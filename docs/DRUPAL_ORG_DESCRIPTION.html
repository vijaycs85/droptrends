DropTrends brings objective, instant health ratings—the DropScore™ (0–100)—directly inside Drupal.org module project pages via a lightweight, privacy-first browser extension.

Choosing Drupal modules today often leads to decision paralysis: outdated code, abandoned issue queues, uncertain Drupal 11 readiness, and multiple competing solutions for the same problem. DropTrends solves this by analyzing key health signals in real time and displaying a clear, actionable letter grade (A+ through F) beside the module title.

Features

  • Instant Health Pill: An unobtrusive badge injected directly beside the module title displaying the overall score (0–100) and letter grade (A+ to F).
  • Interactive Breakdown Drawer: Click the badge to slide open a deep dive into module strengths, potential risks, and recommendations.
  • Drupal 11 & 10 Compatibility Checks: Instantly verify core support, modern PHP 8.2+ compatibility, and recipe readiness.
  • Security Advisory Verification: Immediate visibility into Drupal Security Advisory policy coverage (the shield icon status) and maintainer track records.
  • GitLab CI & Code Quality: Real-time test pipeline status and automated test suite coverage without leaving the project page.
  • One-Click Composer Copy: Quickly copy composer require drupal/module_name right from the drawer.
  • Zero Configuration & Privacy-First: Runs entirely client-side. Zero tracking, zero telemetry, and zero backend latency.

The DropScore™ Evaluation Matrix (0–100)

DropScore calculates an objective score across five weighted pillars:

Pillar Weight Key Signals Evaluated
🛡️ Security & Trust 25 pts Security advisory coverage (shield status), critical advisory history, maintainer trust.
⚡ Maintenance & Velocity 25 pts Last release recency, commit frequency, project status tags, and issue queue velocity.
🚀 Modernity & Compatibility 20 pts Drupal 11 & Drupal 10 core compatibility, PHP 8.2+ support, recipe readiness.
🧪 Code Quality & CI 15 pts GitLab CI test pass rate, automated test presence (Unit, Kernel, Functional), PHPStan status.
📈 Adoption & Community 15 pts Reported active installations, Packagist download velocity, active contributor breadth.

  4. Click Load unpacked and select the extension directory from this repository.

Privacy & Permissions

DropTrends is built with a strict privacy-first architecture:

  • No Tracking: We do not collect, transmit, or monetize any user data, IP addresses, or browsing history.
  • Client-Side Processing: DropScore is calculated directly in your browser using publicly visible metadata on Drupal.org project pages.
  • Minimal Permissions: Only requests permission to inject UI badges on drupal.org/project/* and query public GitLab CI badges on git.drupalcode.org.
